# Why this desk has no front end

Customer references are a coordination problem: who fits the request, what permission covers the audience, who is already busy and which wording is approved. This database keeps the evidence and the weekly queue. A coding agent runs the same CLI an operator can inspect.

The included HTML views show the week, advocate workload and record checks. They are read-only documents, not an application. Draft reference briefs, permission review sheets and story packs use brand.json. Change the business name, logo and colours once.

A hosted community gives customers a self-service login, discussion threads, challenge participation, a mobile experience and notifications. This free desk supplies none of those screens or network services. It does not send email, publish endorsements, pay rewards or synchronise Salesforce. A sales team needing those features has a separate integration and interface project, which Enterprise DNA can scope in its custom version.

Local mode needs no network or server after dependencies are installed. A shared PostgreSQL deployment needs identity, permissions, hosting, backup and a verified restoration plan. Coding-agent subscriptions and infrastructure costs remain yours. Claude Code, Codex, OpenCode and Cursor can operate the same repo through CLAUDE.md and AGENTS.md.
